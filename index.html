功能

符合 ProjectDetail.md 規格全部實裝、可長期運行的穩定版本。

大字時鐘

72 px RobotoMono 數字字型、12 / 24 小時切換、AM/PM 標記。每分鐘部分刷新時間區，DU LUT 乾淨擦舊像素、無 ghosting。

OpenWeather 天氣

當日溫度 + 中文描述 + 96×96 icon（Floyd-Steinberg dither）。每天 11:00 / 23:00 全幀更新；丟到 RP2350 第二核心跑、不阻塞主迴圈。

月曆

今日反白；可選週一或週日為一週起始。跨日 / 跨月 / 跨年自動偵測並部分刷新月曆區。

Wi-Fi 強度

右上角 5 級信號 icon，依 RSSI 動態切換；level 變化時只刷右上角。

NTP 校時

每天 23:59 透過 time.apple.com 同步，30 秒 timeout；支援時區 offset（UTC−12 ~ +14，含半小時時區）。

Web 設定 UI

AP 模式 + 多頁逐步引導：Wi-Fi → 時區 → OpenWeather。RWD 適配手機；mDNS 廣播 epaper.local；RUN 階段也不關閉。

硬體

完整 BOM 三個元件：MCU、電子紙、電池。

MCU

Raspberry Pi Pico 2 W

  • RP2350 (Dual-core ARM Cortex-M33)
  • CYW43439 Wi-Fi + Bluetooth
  • 520 KB SRAM / 4 MB Flash
  • SMP 雙核 → _thread 把天氣 API 丟到第二核心

顯示

Waveshare 3.7" e-Paper HAT

  • 480 × 280，4 階灰 / 1-bit
  • 反射式、180° 視角
  • Partial refresh DU LUT
  • SPI baudrate 4 MHz

電源

18650 鋰電池 × 1

  • 3.7 V nominal / ~3000 mAh
  • e-paper 顯示時不耗電
  • refresh + Wi-Fi 才吃電

架構

13 個模組 cooperative uasyncio + FSM；Web Server 從不關閉。

main.py
  └─ App().run()                  ← uasyncio entry

app.py    FSM (BOOT → AP → STA_TRY → INIT → RUN)
  │
  ├── config.py            ConfigManager + batch()
  ├── wifi_manager.py      AP / STA / scan / rssi_to_level
  ├── mdns.py              LWIP responder + vendored fallback
  ├── ntp.py               time.apple.com + tz offset
  ├── weather.py           OpenWeather + _thread (core 1)
  ├── scheduler.py         1 Hz poll RTC → 5 events
  ├── web_server.py        async HTTP 多頁 /wifi /time /weather
  │
  └── display/
      ├── canvas.py        480×280 landscape + viper transpose
      ├── icons.py         PBM P4 + LRU cache
      ├── fonts.py         FONT_BODY / SMALL / MONO / CLOCK / LABEL
      └── screens/         guide / message / calendar / main_screen

狀態機

BOOT
  └─ config.is_wifi_configured() → no  → AP_CONFIG
                                 → yes → STA_TRY

AP_CONFIG ── POST /wifi ──▶ STA_TRY
STA_TRY ── 成功 ─▶ INIT          失敗 ─▶ AP_CONFIG
INIT ── NTP ✓ + Weather ✓ ─▶ RUN  任一失敗 ─▶ HALT (web 仍開)
RUN ── POST /weather ──▶ INIT (re-init，不重啟)

Scheduler 事件

事件觸發動作
EV_MINUTE分鐘變化render_time + commit_part(TIME_RECT)

EV_LOG_ROTATE每月 1 日 00:00清空 weather.log

開發歷程

從設計到實機 polishing；完整紀錄見 Record.md。

  1. 01

    設計階段

    規格落地（ProjectDetail.md）、關鍵技術決策表、FSM 草圖。確定字型走 NotoSansTC 子集、mDNS 走 LWIP + vendored fallback、座標系用 480×280 landscape。

  2. 02

    資產生成（host 端）

    用 font-to-py 產 218 字 noto20 / noto12 + clock_big；OpenWeather PNG 經 autocontrast + UnsharpMask + Floyd-Steinberg dither 轉 96×96 PBM；vendored cbrand/micropython-mdns。

  3. 03

    display 抽象 + 模組拆分

    LandscapeCanvas (480×280 → 280×480 轉置)、icons.py + LRU cache、fonts alias。把 500+ 行 main.py 拆成 config / wifi / weather / ntp / scheduler 5 個模組。

  4. 04

    Web Server async 化

    改成 asyncio.start_server，多頁 /wifi → /time → /weather → /done，RWD inline CSS ~40 行，時區下拉含半小時時區。

  5. 05

    FSM 主控 + Scheduler

    BOOT / AP_CONFIG / STA_TRY / INIT / RUN / HALT 串接；1 Hz poll RTC emit 6 種事件。/.skip_ntp 測試旁路。

  6. 06

    實機踩坑 ①：部分刷新 ghosting

    每次 commit 後 Sleep() 會丟掉 controller 內 0x26 舊框 RAM，DU LUT 算錯 transition。改成 commit 之間不 init/Sleep，加 _awake 旗標。

  7. 07

    實機踩坑 ②：純 Python 轉置太慢

    360×250 landscape → native 從 ~900 ms 壓到 ~40 ms：寫 @micropython.viper + ptr8 版直接 bit-pack 操作 buffer，@micropython.native 版作 fallback。

  8. 08

    時鐘垂直置中

    WiFi icon 在 x ≥ 440 不跟時間區水平重疊，TIME_RECT 改 (0, 0, 360, 280) 整高置中。font-to-py multi-pass 解算讓 cell padding=0，font.height() 直接拿來算 ty。

  9. 09

    weather.fetch 移到第二核心

    OpenWeather 最壞 190 s 阻塞改用 _thread.start_new_thread 丟到 RP2350 core 1；主核心 200 ms poll done flag，asyncio.sleep_ms 期間 web / scheduler / partial refresh 照常運作。

  10. 10

    AP IP 平台限制

    MicroPython rp2 CYW43 韌體 DHCP server 子網被硬碼成 192.168.4.0/24（micropython#17401、#17977）。採真實 IP 192.168.4.1；start_ap() 讀回 ifconfig 真實值供 guide / mDNS 使用。

部署

用 MicroPico VSCode extension，無需 build step。

  1. 1

    燒 MicroPython 韌體

    Pico 2 W 上燒 MicroPython 1.22+（rp2 / RPI_PICO2_W build）。按住 BOOTSEL 插 USB，把 .uf2 拖進去。

  2. 2

    VSCode + MicroPico

    安裝 paulober.pico-w-go extension，開本專案，狀態列出現「Pico Connected」綠燈即就緒。

  3. 3

    上傳整個專案

    Explorer 樹專案根目錄右鍵 → Upload project to Pico（30–60 秒）。.vscode/settings.json 的 micropico.pyIgnore 會自動跳過 *.md / fonts/ / tools/ / API/ / web/ 等開發用內容。

  4. 4

    Soft Reset

    Command Palette → MicroPico: Soft reset Pico（macOS vREPL 的 Ctrl-D 會被終端機吃掉）。

  5. 5

    初次設定

    沒有 config.json 自動進 AP 模式。手機連 ePaper / paper1234，瀏覽器開 http://192.168.4.1 或 http://epaper.local，跟著 Wi-Fi → 時區 → OpenWeather 三頁設定走完即可。

config.json 範例

{
  "wifi":    { "ssid": "", "password": "" },
  "time":    { "is_24h": true, "week_start": 1, "tz_offset_min": 480 },
  "weather": {
    "api_key": "",
    "city":    { "name": "Taipei", "lat": 25.04, "lon": 121.5 },
    "is_celsius": true
  }
}

已知風險與限制

項目影響緩解
connect_sta (~15 s) / ntp.sync (30 s) 阻塞 event loop web / 時鐘 tick 短暫凍住 使用者主動觸發 / 23:59 觸發、無互動，可接受
/scan 會短暫斷 STA 重新掃描時連線可能中斷 實測後決定是否 cache
AP + STA 同時開的 mDNS 只能綁一個介面 STA_TRY 初次進入時關 AP
AP 子網 DHCP 硬碼 192.168.4.0/24 規格的 192.168.0.1 不可達 採真實 IP，ifconfig 讀回後使用
